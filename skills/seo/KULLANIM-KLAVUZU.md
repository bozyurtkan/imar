## 📊 Ne Tür Analizler Yapar?

### 1. Teknik SEO
- Meta etiketler (title, description, keywords)
- HTML yapısı ve semantik etiketler
- Heading hiyerarşisi (H1-H6)
- Alt text ve görseller
- URL yapısı
- Canonical ve robots direktifleri

### 2. Performans Optimizasyonu
- Core Web Vitals (LCP, FID/INP, CLS)
- Dosya boyutu optimizasyonu
- Lazy loading önerileri
- CSS/JS minification
- Browser caching stratejileri
- CDN önerileri

### 3. İçerik Stratejisi
- Anahtar kelime analizi
- Uzun kuyruk anahtar kelimeler
- LSI (Latent Semantic Indexing) öneriler
- E-E-A-T optimizasyonu
- İçerik derinliği önerileri
- Sesli arama optimizasyonu

### 4. Yapılandırılmış Veri (Schema.org)
- Organization schema
- LocalBusiness schema
- Product/Service schema
- FAQ schema (Featured Snippets için)
- BreadcrumbList schema
- Article/BlogPosting schema

### 5. LLM Optimizasyonu
- Claude görünürlüğü için yapılandırma
- ChatGPT için içerik optimizasyonu
- Gemini ve diğer AI'lar için stratejiler
- Yapılandırılmış veri formatları
- Faktual ve doğrulanabilir içerik önerileri

### 6. Coğrafi Hedefleme (GEO)
- Türkiye ve Gaziantep için özel optimizasyon
- Hreflang etiketleri
- LocalBusiness schema
- Yerel anahtar kelime stratejisi
- NAP (Name, Address, Phone) tutarlılığı

### 7. Mobil Optimizasyon
- Mobile-First Index uyumu
- Responsive design kontrolü
- PWA (Progressive Web App) önerileri
- Touch-friendly UI kontrolü
- Mobil performans optimizasyonu

### 8. Güvenlik ve Güvenilirlik
- HTTPS kontrolü
- Güvenlik header'ları
- GDPR ve KVKK uyumluluğu
- Privacy policy kontrolleri

## 📤 Alacağınız Çıktılar

### 1. Detaylı Analiz Raporu
`antigravity-seo-report.md` - Kapsamlı markdown rapor:
- Genel durum özeti
- Güçlü yönler ve iyileştirme alanları
- Her kategori için detaylı analiz
- Somut öneriler ve kod örnekleri
- Öncelikli aksiyon planı (HEMEN, KISA, ORTA, UZUN VADE)

### 2. Hazır Kod Dosyaları

**optimized-index.html**
- Meta etiketler eklenmiş
- Semantik HTML yapısı
- Schema.org markup'ları
- Performance optimizasyonları

**schema-markup.json**
- Organization schema
- LocalBusiness schema
- FAQ schema
- Product schema
- Kopyala-yapıştır hazır JSON-LD kodları

**robots.txt**
- Optimize edilmiş robots direktifleri
- Sitemap referansları
- Crawler yönetimi

**sitemap.xml**
- XML sitemap şablonu
- Öncelik ve frekans ayarları
- Tüm sayfalar için yapı

**htaccess-rules.txt** veya **nginx-config.txt**
- Redirect kuralları
- Güvenlik header'ları
- Gzip sıkıştırma
- Browser caching
- HTTPS yönlendirmeleri

**meta-tags.html**
- Tüm meta etiketler bir arada
- Open Graph etiketleri
- Twitter Card etiketleri
- Canonical link'ler

**performance-checklist.md**
- Adım adım performans optimizasyon listesi
- Core Web Vitals iyileştirme adımları
- Kontrol noktaları
